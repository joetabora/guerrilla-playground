### PHASE 3: Set Up Branch Protection (3 minutes)

1. **Navigate to Branches**
   - Settings → Branches (left sidebar)
   - Click "Add branch protection rule"

2. **Branch Name Pattern**
   - Enter: `main`

3. **Enable Protection Rules:**
   - ☐ Check "Require a pull request before merging"
     - Set "Required approvals" to: **1**
   - ☐ Check "Require status checks to pass before merging"
   - ☐ Check "Require branches to be up to date before merging"
   - ☐ Check "Do not allow bypassing the above settings" (includes admins)

4. **Click "Create" at bottom**

**✅ Production branch is now protected!**
