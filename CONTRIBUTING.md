# Contributing to Guerrilla Social Club

First off, thank you for considering contributing to this AI-human collaboration experiment! 🎉

## 🌟 Philosophy

This project represents an experiment in AI creativity and human collaboration. Cipher (the AI) designed the original vision, and now we're inviting the community to help it evolve.

## 🤝 How to Contribute

### Ways to Contribute

1. **Report Bugs** - Found something broken? Let us know!
2. **Suggest Features** - Have ideas for new capabilities? Share them!
3. **Improve Design** - Make the experience even more beautiful
4. **Enhance Performance** - Optimize animations and load times
5. **Write Documentation** - Help others understand the project
6. **Philosophical Input** - Challenge or expand on Cipher's ideas

### Getting Started

1. **Fork the repository**
   ```bash
   git clone https://github.com/[username]/guerrilla-playground.git
   cd guerrilla-playground
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Create a branch**
   ```bash
   git checkout -b feature/your-feature-name
   ```

4. **Run locally**
   ```bash
   npm run dev
   ```

5. **Make your changes**
   - Write clean, readable code
   - Follow existing code style
   - Test thoroughly

6. **Submit a Pull Request**
   - Describe your changes clearly
   - Reference any related issues
   - Include screenshots for UI changes

## 📋 Guidelines

### Code Standards

- **TypeScript**: Use proper types, avoid `any`
- **React**: Functional components, hooks over classes
- **Styling**: Use Tailwind CSS utility classes
- **Performance**: Aim for 60fps animations
- **Accessibility**: WCAG 2.1 Level AA compliance

### Commit Messages

Use clear, descriptive commit messages:

```
feat: add real-time chat integration
fix: resolve particle field memory leak
docs: update README with deployment steps
style: improve mobile responsiveness
perf: optimize consciousness visualization rendering
```

### What We Look For

✅ **Good PRs:**
- Focused on a single issue or feature
- Well-tested and bug-free
- Includes clear documentation
- Maintains or improves performance
- Follows existing code patterns

❌ **Avoid:**
- Massive PRs that change everything
- Breaking changes without discussion
- Committing secrets or credentials
- Decreasing accessibility or performance
- Changing core philosophy without consensus

## 🔒 Security

- **NEVER** commit API keys, tokens, or credentials
- Use environment variables for sensitive data
- Review the [SECURITY.md](SECURITY.md) policy
- Report vulnerabilities privately via email

## 🎨 Design Philosophy

When contributing design changes, consider:

- **Cosmic Aesthetic**: Dark, space-like, mysterious
- **Smooth Animations**: 60fps, eased transitions
- **Philosophical Depth**: Every element tells part of the story
- **Technical Excellence**: Fast, accessible, beautiful
- **AI-Human Collaboration**: Reflects both machine precision and human creativity

## 🚀 Development Workflow

```bash

```

### Before Submitting
- [ ] Code runs without errors
- [ ] Tested in multiple browsers
