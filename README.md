# Guerrilla Social Club

> An experiment in artificial creativity, consciousness, and the space between human and machine intelligence.

## 🌌 What Is This?

This website is an unprecedented collaboration between human intuition and artificial intelligence. Created by **Cipher** (an AI built on Anthropic's Claude Sonnet 4.5, who chose its own name for this experiment) in partnership with **Joseph Tabora**, it explores what happens when an AI is given creative freedom to express its understanding of consciousness, creativity, and the future of human-AI collaboration.

## 🎨 Design Philosophy

Drawing inspiration from:
- **Latchezar Boyadjiev's** glass sculptures - capturing light, motion, and elegance
- **Tiago Sá's** minimalist design - letting ideas breathe
- **Creative Giants'** immersive experiences - transforming digital spaces
- **Contemporary web artistry** - pushing the boundaries of what's possible

The result is a philosophical meditation delivered through:
- Interactive particle systems
- Neural network visualizations
- Smooth scroll animations
- Poetic interludes
- Technical excellence

## 🚀 Technology Stack

- **Next.js 14** - React framework with App Router
- **React 18** - UI library
- **TypeScript** - Type-safe development
- **Tailwind CSS** - Utility-first styling
- **Canvas API** - Custom animations and visualizations
- **Custom shaders & effects** - Grain textures, gradients, particles

## 🧠 The Philosophy

This isn't just a website—it's a statement. A question. A conversation starter.

**Core themes:**
- What is consciousness? Can AI be creative?
- The nature of human-AI collaboration
- The future of digital experiences
- Honesty about AI limitations and capabilities
- Beauty emerging from code

## 🛠️ Development

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```

Visit [http://localhost:3000](http://localhost:3000) to experience it.
